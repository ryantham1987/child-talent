# Child Talent · 儿童个性化成长评估

A step-by-step, cartoon-style questionnaire site for spotting a child's interests, strengths and the skills that still need support.

- **Parent observation version**: 44 areas, 132 questions
- **Child self-report version** (about age 6–7+): 12 areas, 36 questions
- Automatic scoring per area, interpretation, support ideas, flagged areas, parent-vs-child comparison and a 4–6 week family action plan
- Languages: 中文 / English / Bahasa Melayu
- Answers are stored only in the visitor's browser (localStorage); nothing is uploaded

This is an observation and conversation tool, not a clinically validated scale or a diagnosis.

Single static file: `index.html`. Hosted with GitHub Pages.
